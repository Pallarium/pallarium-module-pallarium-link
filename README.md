# Pallarium Link

Pair two Pallarium PCs. Tell me to install a program or send a whitelisted action to the other one. Pairing code, signed requests, approval on the receiving PC.

A **[Pallarium](https://pallarium.app) module** — a self-contained feature you can add to Pallarium.

## Install

Open Pallarium → **Tools → Modules → Discover on GitHub**, search for this repo, and click **Install**. It drops in and turns on live — no restart.

_Or_ download the `.fcmod` from Releases and use **Import .fcmod**.
